أهلاً بك. أدخل مفتاح الدخول لتعديل محتوى الموقع ونشره.

كيف أحصل على مفتاح الدخول؟
  1. افتح github.com/settings/personal-access-tokens/new
  2. اختر Only select repositories ثم mubader-preview.
  3. من Repository permissions اجعل Contents على Read and write.
  4. اضغط Generate token وانسخه هنا. يُحفظ في هذا المتصفح فقط.
